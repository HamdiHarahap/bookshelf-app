# Bookshelf App 

Website ini merupakan submission kursus  [Belajar Membuat Front-End Web untuk Pemula](https://www.dicoding.com/academies/315/). Di website ini kita bisa menampilkan buku, menambahkan data buku, mengedit buku, mengubah buku menjadi dibaca atau belum, mencari buku, dan menghapus buku. Semua data buku akan disimpan di LocalStorage
